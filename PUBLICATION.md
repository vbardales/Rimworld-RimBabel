# Publishing RimBabel

What the Workshop page asks for and the repository holds nowhere else. Written before any upload, and kept for whoever
picks this mod up later.

**Nothing is published and no Workshop item exists.** There is no `Mod/About/PublishedFileId.txt`, so the first
upload, `0.1.0`, has not happened. Once the item exists, its id goes into that file, which is committed at once, and
`CHANGELOG.md` opens with `## [0.1.0]` ("creation of a publishId file").

## The one-way parts

- **The description.** The game sends it only when it creates the item. From `1.0.0` the CI sends it from the Markdown
  block under `## Steam description` below, which also generates the `<description>` of `About.xml`.
- **The packageId**: `nelim.rimbabel`. Changing it after publication disables the mod for everyone.
- **`About/PublishedFileId.txt`**: commit it immediately, or the next upload creates a second item.
- **Steam creates every item private.** The owner switches it to public by hand.

## Open before a first upload

- The GitHub repository and its name (the description ends with `Source code on GitHub`, which needs it).
- `ModIcon.png` and `Preview.png`: generated by the owner only.
- The gallery, in the order below; none of it exists.
- Dependencies: none declared. Harmony will be added the day the in-game part uses it.
- Adult-content boxes: not applicable, to be confirmed on the page.

## Screenshots, in upload order

None exist. The first slot goes to the image that sells the mod best: a translation package generated and its manifest
open, with the coverage of a real mod visible. The rest depend on what the interface looks like once it exists.

## Steam description

```markdown
Translate RimWorld mods into your language, once, the same way in every mod, and ship the result as a mod of its own.

RimBabel reads the texts of a mod, translates what is missing with the engine you choose, and writes a translation package: a normal RimWorld mod that never touches the mod it translates. Run it again when the source mod changes and only the texts that moved are translated again.

Work in progress.
```
